# ANSI reference

Design asset for the Autobuild web app's ANSI visual world, chosen by the maintainer on 2026-10-24.

- `index.html` — static reference page. Views and grounds switch by hash: `#builds`, `#builds-menu`, `#members`, `#members-confirm`, `#orgs`, `#orgs-empty`, `#projects`, `#connect`, `#signin-refused`; add `&theme=light` or `&theme=dark`, and `&bare` to hide the reference strip. Its CSS custom properties are the proposed tokens for both grounds.
- `screens/` — captures of every view in both grounds at 1440px, and Builds, Members and Projects at 390px.
- `product/PRODUCT.md` — the revised product record (tiers, audience, operator agents, roles, parity, visual starting point).
- `product/surface-brief.md` — the revised surface brief for `packages/hosted-store-service`, including the ANSI direction contract (seed key c4eff9b1).

Sample people, organizations, projects and builds on the page are synthetic.
